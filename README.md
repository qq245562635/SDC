# 《逃离三国》（暂定名）

俯视角 2D 动作肉鸽搜打撤游戏。现代穿越者每局通过时空裂隙闯进一场三国名战役，打名将、夺名将装备、护送红颜，在“历史修正力”抹掉自己之前撤回庄园。玩法参考搜打撤类（如《逃离鸭科夫》）和哈迪斯式肉鸽，但是非射击，以冷兵器近战为主。

## 已定决策

- 题材：穿越者闯三国各战役（公版历史题材，不用任何现有三国游戏的造型和美术）。
- 视角与维度：俯视角斜 45 度，2D。
- 引擎：Godot 4（推荐）。
- 美术风格：A「水墨粗线卡通」，深褐粗墨线 #2B1D16、平涂加一档硬阴影、宣纸纹理。
- 红颜系统按全年龄尺度做。
- 分工：主策 Claude 1 号，主程 Claude 2 号，主美 Codex，见 [AGENTS.md](AGENTS.md)。
