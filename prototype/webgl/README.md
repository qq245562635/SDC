# T001 WebGL 玩法原型

虎牢关一局搜打撤。Phaser 3.80.1（CDN），无构建步骤。

## 运行

- Windows：双击 `start.bat`，浏览器打开 http://localhost:8000/
- 其他：在本目录运行 `python3 -m http.server 8000`

不能直接双击 `index.html`：Chrome 禁止 file:// 页面读取本地贴图。

## 操作

电脑：WASD 移动 · 鼠标瞄准 · 左键/J 连击 · 右键/K 重击（温酒斩华雄时按住蓄力） · 空格 翻滚 · E 搜箱 · F 强光手电 · Q 当阳一吼 · Tab 背包 · 1/2/3 选将魂

手机（横屏）：左半屏按住拖动 = 浮动摇杆 · 右下“攻”点按连击、按住 0.4 秒重击 · “滚”朝摇杆方向翻滚 · 靠近宝箱出现“搜” · 手电、当阳一吼有才显示 · 右上 包 / 停 / 全屏 · 将魂卡、营门、结算直接点。攻击自动朝前方 120° 内 240px 以内最近的敌人。

背包（T009）：按重量算，开局 Lv1 20 斤，超过一半开始减速；装不下的自动给宝驹（2 格，不算重量）。背包界面里点物品在背包和宝驹间转移，拖到护心镜存安全位，“丢”扔在脚下可捡回。数值在 `game.js` 顶部。

平台自动判断（有触点且主指针是手指）。调试：网址加 `?touch=1` 强制触屏，`?touch=0` 强制键鼠。

## 调试

控制台里 `__run` 是当前局（Run 场景），`__result` 是上一局结算。

## 文件

- `game.js`：全部逻辑，数据表在文件顶部（敌人、物品、宝箱、将魂、营门）。
- `rig.html`：拆件拼装调试页（主角、联军兵站姿 + 摆臂，吕布关键姿势）。空格 摆臂，J 关节点，M 镜像。
- `assets/art/`：T002 正式美术，`python3 tools/sync_art.py` 从 `art/` 生成（按 1080p 显示尺寸缩好，`manifest.js` 记原点、包围盒、关节点），别手改。主美更新美术后重跑一次。
- `assets/key_art.jpg`：标题背景，来自第一批概念图（U06 主界面是 P1，到时替换）。
