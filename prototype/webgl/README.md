# T001 WebGL 玩法原型

虎牢关一局搜打撤。Phaser 3.80.1（CDN），无构建步骤。

## 运行

- Windows：双击 `start.bat`，浏览器打开 http://localhost:8000/
- 其他：在本目录运行 `python3 -m http.server 8000`

不能直接双击 `index.html`：Chrome 禁止 file:// 页面读取本地贴图。

## 操作

电脑：WASD 移动 · 鼠标瞄准 · 左键/J 连击 · 右键/K 重击（温酒斩华雄时按住蓄力） · 空格 翻滚 · E 搜箱 · F 强光手电 · Q 当阳一吼 · Tab 背包 · 1/2/3 选将魂

手机（横屏）：左半屏按住拖动 = 浮动摇杆 · 右下“攻”点按连击、按住 0.4 秒重击 · “滚”朝摇杆方向翻滚 · 靠近宝箱出现“搜” · 手电、当阳一吼有才显示 · 右上 包 / 停 / 全屏 · 将魂卡、营门、结算直接点。攻击自动朝前方 120° 内 240px 以内最近的敌人。

背包（T011 格子背包）：Lv1 6×3 / 20 斤，Lv2 7×4 / 35 斤，Lv3 8×5 / 50 斤，格子和重量同时限制，超过一半重量开始减速。大件占多格，钱币一格叠 20。装不下的自动给宝驹（2 个驮位，不论大小、不算重量）。背包界面：拖动移动（PC 按 R、手机点“旋转”转向，拖到格子外丢弃），右键 / 长按出菜单（旋转、转移、丢弃），“整理”从大到小重排。数值在 `game.js` 顶部；控制台 `__inv` 是格子函数。

平台自动判断（有触点且主指针是手指）。调试：网址加 `?touch=1` 强制触屏，`?touch=0` 强制键鼠。

## 调试

控制台里 `__run` 是当前局（Run 场景），`__result` 是上一局结算。

## 文件

- `game.js`：全部逻辑，数据表在文件顶部（敌人、物品、宝箱、将魂、营门）。地面每间营帐重画：四块素土底图混铺，加 30–50 个贴花（`paintGround`）。
- `rig.js`（T006）：拆件骨骼动画。按 T004 `assets.json` 的关节、挂点、握点拼装，不手调；动作是关键帧轨道（`骨骼.属性`），`play(动作, { blend, speed })` 交叉过渡。结构按 Godot 的 Skeleton2D / Bone2D / AnimationPlayer 写，文件头有对照。主角、联军兵、弓手用它，吕布仍是姿势图。
- `rig.html`：骨骼动画调试页。上方按钮切动作，滑块调速度和过渡时间；每个角色右边是静止拼装叠待机姿势图。J 关节点，M 镜像，O 叠图，空格 暂停。
- `assets/art/`：T002 / T004 正式美术，`python3 tools/sync_art.py` 从 `art/` 生成（按 1080p 显示尺寸缩好，`manifest.js` 记原点、包围盒、关节、挂点、贴花旋转限制），别手改。主美更新美术后重跑一次。
- `assets/key_art.jpg`：标题背景，来自第一批概念图（U06 主界面是 P1，到时替换）。
