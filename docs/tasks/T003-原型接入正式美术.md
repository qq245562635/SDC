# T003 原型接入 T002 正式美术

- 角色：主程
- 状态：待领取（等 PR #2 合并后开工）
- 分支：`dev/T003-art-hookup`
- 目标：把 WebGL 原型里的切图和色块换成 T002 的 P0 美术，并验证拆件能否拼成角色，为 Godot 版铺路。

## 范围

1. 读 `art/delivery/T002/assets.json`，按里面的 `display_scale`、`origin_normalized` 摆放（不要用图片外框当脚底）。构建时把用到的图复制或链接到 `prototype/webgl/assets/`，不改 `art/`。
2. 角色：主角、三色联军兵、弓手改用关键姿势图切换（待机 / 走 / 前摇 / 攻击 / 受击 / 倒地；主角加翻滚、搜刮、重击）。暂不做逐帧动画。
3. 场景：地面改用 E01 地砖随机铺；栅栏、营门用 E03；营帐用 E04（随机完好或破损）；加 E05 帅旗、E06 辎重车、E07 火盆配 V03 火焰（8fps）。
4. 物件和特效：宝箱用 E08，出货光柱用 V05 六色，刀光用 V01，受击用 V02（破防时盖“破”印），撤离点用 E09。
5. UI：HUD 用 U01，背包用 U02（格子、稀有度框），将魂卡用 U03，营门图标按 U04 对应：将魂→spirit，宝箱→supplies，精英→danger，郎中→merchant（暂代），撤离用 E09 小图。物品图标用 I01/I02，把原型物品表对应到现有图标，对应不上的保留色块。
6. 拼装验证：用主角和联军兵的拆件（头、身、臂、腿、武器、背饰）在一个调试页 `prototype/webgl/rig.html` 拼出站姿，加简单摆臂。记录遮挡顺序、关节点和镜像时的问题，写进 PR。
7. 删掉 `tools/extract_sprites.py` 和对 `art/concept/` 的依赖（如果全部换完）。

## 不做

吕布 Boss 玩法（只要素材能显示即可，可在调试页里摆出来）、新玩法、数值改动。

## 验收

- [ ] GitHub Pages 上能玩，控制台无报错，加载不超过 10 秒（总资源大小写进 PR）。
- [ ] 上面 1–5 条在游戏里都能看到，没有图被拉伸或脚底悬空。
- [ ] `rig.html` 能看到拼好的主角和联军兵，PR 里写明拼装问题清单，需要主美返工的单独列出。
- [ ] PR 附截图：战斗、搜箱、背包、三选一、调试页。
