# T008 试玩反馈第一轮：搜箱提示、移速、翻滚、摇杆

- 角色：主程
- 状态：待领取
- 分支：`dev/T008-playtest-1`
- 来源：用户 2026-11-05 在 PC 和手机上试玩后的反馈。

## 范围

1. **E 提示看不清、没对齐（PC）。** 去掉屏幕底部那行文字提示，改为在宝箱头顶显示按键提示：一个 U01 slot 框，里面写“E”，下面写“搜索”。字号至少 20px，深色描边，和宝箱中心对齐，跟着宝箱走。触屏下框里显示手指图标或“搜”字。底部的撤离提示保留。
2. **宝箱在地上要有提醒。** 没搜过的宝箱：
   - 脚下有一圈呼吸光（按宝箱档次分白、铜、金三色），1.2 秒一个周期；
   - 每隔 3 秒闪一下高光；
   - 主角进入 160px 范围后，头顶出现第 1 条的按键提示，箱子轻轻弹一下。
   搜完的箱子去掉光圈，压暗 30%。
3. **翻滚距离缩短。** 160 → 120px，时长保持 0.2 秒，无敌时间不变。“锦马超冲”的冲锋距离也按同样比例缩短。
4. **移速降低。** 基础移速 300 → 240px/s。翻滚和攻击时的突进距离不变；敌人移速不改，先看手感。
5. **手机摇杆放大 1.3 倍。** 底座和摇杆头都放大，最大拖动半径同步放大。

docs/02 的数值已经同步改好：移速 240，翻滚 120。

## 验收

- [ ] PC 上提示清楚，和宝箱对齐；没搜的宝箱远远就能看出来。
- [ ] 移速、翻滚和摇杆按上面的数值改好，数值写在 `game.js` 顶部。
- [ ] PC 和触屏都没有报错，Pages 上能玩。
