# T005 走路过渡动画（用现有姿势图）

- 角色：主程
- 状态：待领取
- 分支：`dev/T005-walk-cycle`
- 目标：用户试玩时反馈走路时腿不动。骨骼动画要等 T004 的拆件，在那之前先用现有的关键姿势做出“在走”的感觉。

## 范围

1. 主角：移动时在 `hero_run` 和 `hero_idle` 两张图之间切换，每秒 8 次左右，按移速调快慢。联军兵、弓手用 `walk` 和 `idle` 切换，每秒 6 次左右。
2. 叠加程序动作：每切一帧上下颠一次（约 4px）。落地那一帧稍微压扁（x 1.06、y 0.94），起来时还原。身体随步伐左右小幅摇摆，不超过 4°。
3. 脚下扬尘：主角跑动时每步在脚下冒一小团墨点或尘土（V02 墨滴缩小即可），敌人不加。
4. 停下时回到待机图，不要卡在中间那一帧。
5. 参数集中写在 `game.js` 顶部，方便调手感。

## 不做

骨骼动画（T006）、新美术。

## 验收

- [ ] 主角和敌人走起来脚步明显在动，停下自然。
- [ ] Pages 上能玩，控制台没有报错。
