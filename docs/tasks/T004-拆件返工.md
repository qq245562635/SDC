# T004 角色拆件返工（侧身拆件 + 实测关节）

- 角色：主美
- 状态：待领取
- 分支：`art/T004-rig-parts`
- 目标：让 C01 主角、C02 联军兵、C03 弓手的拆件能直接在 Godot 里拼成侧身角色做骨骼动画。问题来自 T003 的 `prototype/webgl/rig.html` 拼装验证（PR #4）。

## 范围

1. **改成侧身视角。** 拆件按侧身朝右重画，和关键姿势图、游戏朝向一致。左右朝向靠镜像，接受镜像后光源和持刀手跟着翻转。
2. **比例统一。** 拆件拼出来的高度要等于同角色待机姿势图的高度（主角显示 140），头件按姿势图比例画。
3. **实测关节点。** 在 `assets.json` 里给每个部件写实测的 `joint_pivot`（像素）；武器另给 `grip`（握把点）。不要再用统一的模板值。
4. **挂点。** 身体件给出 `attach`：`neck`、`shoulder_l`、`shoulder_r`、`hip_l`、`hip_r`；手臂给 `hand`。
5. **层级。** 每个部件给 `z`，从后到前按：背饰 → 远侧腿 → 近侧腿 → 远侧臂 → 身体 → 头 → 武器 → 近侧臂。
6. **主角背饰。** 外卖箱按侧身背在身后重画，去掉多余的圆环。
7. **地砖。** E01 每块中间偏深，铺开后格子感明显。把明暗调匀，中间不要比边缘深，保持 24px 边缘一致。

## 不做

吕布拆件（等 Boss 任务）、逐帧动画、新动作。

## 验收

- [ ] 三个角色的拆件按 `assets.json` 拼起来，和待机姿势图叠在一起时轮廓误差不超过 10px（显示尺寸）。
- [ ] 刀和枪握在手里，不穿过身体，也不挡脸。
- [ ] 附一张拼装对照图和一张 4×4 地砖铺开图。
- [ ] 主程跑 `rig.html` 不用手调就能拼对（由主程在 PR 里确认）。
