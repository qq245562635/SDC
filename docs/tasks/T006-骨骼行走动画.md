# T006 拆件骨骼动画

- 角色：主程
- 状态：待领取
- 分支：`dev/T006-rig-anim`
- 目标：主角、联军兵、弓手改用拆件骨骼动画，走路时交替迈腿和摆臂。不做临时方案。

T004 合并后开工，直接用 T004 的正式数据。

## 数据约定（`art/delivery/T004/assets.json` 里每个部件）

| 字段 | 含义 |
| --- | --- |
| `part` | head / body / arm_l / arm_r / leg_l / leg_r / weapon / back |
| `joint_pivot` | 部件自身的旋转点，像素，基于 2 倍画布 |
| `attach` | 只在 body 上：neck、shoulder_l、shoulder_r、hip_l、hip_r 五个挂点，像素 |
| `hand` | 只在手臂上：手的位置，武器挂在这里 |
| `grip` | 只在武器上：握把点 |
| `z` | 绘制顺序，0 在最后 |

## 范围

1. rig 模块：按约定拼装，支持镜像（左右朝向），提供 `play(动作)`，动作可以混合过渡。
2. 动作：
   - 待机呼吸。
   - 走（主角是跑）：交替迈腿、反向摆臂、身体上下起伏，步频跟移速走。
   - 主角：三段连击、重击、翻滚、搜刮。
   - 敌人：前摇、出手（联军兵刺击，弓手拉弓）。
   - 通用：受击、倒地。
3. 游戏里用 rig 替换关键姿势图。吕布暂时保持姿势图。
4. `rig.html` 加动作切换按钮，用来调参数。
5. 地面改成“底图加贴花”：用 T004 的 4 块素土底图混铺，再按 `assets.json` 的旋转限制和缩放范围，在世界坐标里随机撒 30–50 个贴花，避开门和出生点。旧的 16 张地砖不再使用。
6. 结构按 Godot 的 Skeleton2D / AnimationPlayer 来设计，方便以后移植。
