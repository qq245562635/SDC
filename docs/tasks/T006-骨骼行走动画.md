# T006 拆件骨骼行走动画

- 角色：主程
- 状态：等 T004 合并后开工
- 分支：`dev/T006-rig-walk`
- 目标：用 T004 的侧身拆件，给主角、联军兵和弓手做骨骼动画，替换 T005 的两帧切换。

## 范围

1. 按 `assets.json` 里的关节点、挂点和 `z` 拼装，不手调。
2. 动作：待机呼吸、走（主角是跑）、攻击（主角三段连击加重击，敌人前摇和出手）、受击、倒地。走路循环要有交替迈腿和摆臂。
3. 左右朝向用镜像。
4. 做成可复用的 rig 模块，Godot 版照这个结构移植。

## 验收

- [ ] 三个角色走路时腿交替迈步，攻击和受击都能看出来。
- [ ] 帧率不低于 T005 版本，控制台没有报错。
