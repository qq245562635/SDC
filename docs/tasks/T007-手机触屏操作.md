# T007 手机触屏操作

- 角色：主程
- 状态：待领取
- 分支：`dev/T007-touch`
- 目标：手机浏览器里能完整玩一局。电脑保持键鼠，手机用触屏，按平台自动切换。

## 平台判断

- 有触屏且 `matchMedia('(pointer: coarse)')` 为真时用触屏方案，否则用键鼠。
- 触屏方案下不显示键盘提示，标题页改为“点击开始”。
- 方便调试：URL 带 `?touch=1` 时强制用触屏，带 `?touch=0` 时强制用键鼠。

## 触屏布局（横屏）

| 位置 | 控件 | 作用 |
| --- | --- | --- |
| 左半屏任意处 | 浮动摇杆 | 按下的地方出现摇杆，拖动控制移动，松手消失 |
| 右下大键 | 攻击 | 点按：连击；按住 0.4 秒：重击（温酒斩华雄时按住蓄力） |
| 攻击键左上 | 翻滚 | 朝摇杆方向翻滚；摇杆没动时朝面朝方向 |
| 攻击键上方 | 搜 | 只在靠近宝箱时出现 |
| 攻击键旁两个小键 | 道具（强光手电）、将魂技（当阳一吼） | 有道具或技能时才显示，显示剩余次数和冷却圈 |
| 右上角 | 背包、暂停 | 替代 Tab |

- 按键直径至少 64px（按 720p 画面算），半透明，用 U01 的 slot 框。
- 支持多点触控：边走边按攻击、翻滚。

## 瞄准

手机上没有鼠标。攻击时自动朝前方 120° 内最近的敌人（240px 以内）出手；附近没有敌人时，朝摇杆方向或面朝方向。

## 其他

- 竖屏时显示“请横屏游玩”的提示。
- 加一个全屏按钮（Fullscreen API，iOS 不支持就隐藏）。
- 禁止页面滚动、双击缩放和长按菜单（`touch-action: none`、`user-select: none`）。
- 将魂卡、营门、结算页都能直接点。

## 不做

手柄、陀螺仪、按键自定义。

## 验收

- [ ] 电脑上的操作不变。
- [ ] Chrome 设备模拟（iPhone 14 和 Pixel 7 横屏）里能用触屏完整打一局：移动、连击、重击、翻滚、搜箱、背包、三选一、撤离、结算。
- [ ] 同时按摇杆和攻击键没有冲突，翻滚不会被吞。
- [ ] Pages 上用真手机打开能玩（请用户试）。
- [ ] PR 附触屏布局截图。
