# T012 角色腿部重画（成对直腿）

- 角色：主美
- 状态：待领取
- 分支：`art/T012-legs`
- 来源：T006 骨骼动画暴露的问题，见 [PR #10 评论](https://github.com/qq245562635/SDC/pull/10#issuecomment-6658745383)。

## 问题

- 两条腿的画法不一样。主角的远侧腿是宽裤腿加靴子，近侧腿却是绑腿加布鞋，走起来像换了一条腿。
- 近侧腿画成了迈步中的样子，自带倾角：主角 −11°，弓手 −34°，联军兵 −54°。程序把腿摆直以后，联军兵的鞋底是斜的。

## 范围

1. 主角、联军兵（三色）、弓手，每个角色重画一对腿：
   - 远侧腿和近侧腿用同一种裤子和鞋；
   - 都是笔直竖着的站立状态，倾角 0°；
   - 鞋底水平。
   远侧腿可以稍暗、略窄，表现前后关系。
2. 腿长和宽度跟原来一样，关节点、`z` 和 T004 的 `assets.json` 字段格式保持不变，替换后主程不用改代码。
3. 待机姿势的站姿由程序摆出来，美术不用画成迈步的样子。

## 验收

- [ ] 三个角色的两条腿风格一致、竖直、鞋底水平。
- [ ] 主程重跑 `tools/sync_art.py` 后，`rig.html` 直接拼对，走路和跑步时两腿看起来是同一双。
