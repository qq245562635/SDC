# 《逃离三国》游戏策划案

Nov 5, 2026 · @Aoi Ueda

定位：《逃离三国》是一款俯视角 2D 动作肉鸽搜打撤。现代穿越者被困乱世，每局通过时空裂隙闯进一场三国名战役，打名将、抢名将装备、解救红颜，在“历史修正力”把你抹掉之前撤回自己的庄园。主角不是曹操、不是任何名将，所以所有战役都能去。

## 概念：穿越者闯三国战役

### 一句话卖点

“虎牢关捡方天画戟，长坂坡救下糜夫人，赤壁火里抢兵书——带得出来才算你的。”

### 为什么这个设定成立

| 问题 | 这个设定怎么解决 |
| --- | --- |
| 主角不被某一方绑死 | 穿越者是局外人，魏蜀吴群雄的战役都能去 |
| 为什么要“撤离” | 时空裂隙只开一小会，待久了历史修正力会来抹除你 |
| 为什么反复打同一场 | 每次进入都是一条新的平行时间线，地图、宝物和将领随机，天然适配肉鸽 |
| 名字要是“逃离 XXX” | 《逃离三国》句式与《逃离塔科夫》一致，又不局限于单场战役 |
| 高大上、受众大 | 三国是国内最大的历史题材，穿越 + 红颜是网文验证过的爆点 |

### 备选名字

| 名字 | 说明 |
| --- | --- |
| 逃离三国（首推） | 直白、好搜、和搭打撤头部产品同句式 |
| 逃离乱世 | 更开放，以后可以扩展到其他朝代 |
| 三国搬砖人 | 偏搫笑、打工人梗，适合短视频传播 |

先前讨论过的西游小妖、鼠鼠摸金、摸金校尉和《逃离华容道》已放弃：前三个不够大气，华容道会把主角限定在曹操。

## 蹭热点与侵权边界

可以蹭的是玩法、题材和圈内梗；不能蹭的是别人的名字、角色、美术和独创表达。《逃离鸭科夫》蹭塔科夫是“玩法类型 + 谐音梗 + 自己的鸭子角色”，没有用对方的角色和素材，这是可以照抄的做法。

| 做法 | 风险 | 说明 |
| --- | --- | --- |
| 借玩法类型（搜打撤、哈迪斯式肉鸽、基地养成） | 低 | 玩法和规则本身不受著作权保护，但 UI 布局、图标、数值表不要照抄 |
| 用公版题材（西游记、山海经、封神演义等古典作品） | 低 | 原著已过版权期，但影视、动画、游戏里的具体造型仍受保护，如《黑神话》的悟空造型、《浪浪山小妖怪》的角色形象 |
| 用圈内梗（鼠鼠、摸金、出货、大红、打工人） | 低 | 通用词汇，但上架前查一下商标库，游戏名里的词可能已被注册 |
| 谐音梗游戏名（像“塔科夫→鸭科夫”） | 中 | 没有对方授权时，容易被告商标混淆或不正当竞争；不要再谐音“鸭科夫”本身 |
| 在宣传语里写“类鸭科夫”“哈迪斯类” | 中低 | 用于描述玩法一般可以，不要用对方 Logo、截图或暗示官方合作 |
| 彩蛋致敬（一只路过的鸭子 NPC、一句台词） | 中低 | 数量要少，造型要自己画，不能是对方角色的复刻 |
| 直接用别家角色名、角色造型、音乐、美术 | 高 | 著作权和商标双重风险，Steam 和国内平台都会下架处理 |
| 用 AI 生成“像某游戏风格”的图 | 中 | 提示词里不要写游戏名、画师名；Steam 要求在商店页披露 AI 生成内容 |

### 三国题材的具体红线

- 《三国志》《三国演义》和历史人物是公版，关羽、吕布、貂蝉、青龙偃月刀、方天画戟都可以直接用名字。
- 要避开的是具体造型：光荣的《真三国无双》《三国志》系列、《王者荣耀》的三国英雄、《三国杀》的卡面、《卧龙：苍天陨落》。不要用它们的服装配色、标志性发型和特效做参考。
- 《逃离三国》“穿越三国”类名字很可能已有人注册，定名前在中国商标网查第 9 类和第 41 类，注册了就加副标题或换名。

### 红颜 / 后宫系统的风险

后宫是个强卖点，但尺度决定你能上哪些平台。建议做成“红颜知己”：可以好看、可以暗示感情，但不做裸露和性内容。

| 尺度 | Steam | 国内版号 | 影响 |
| --- | --- | --- | --- |
| 全年龄红颜（推荐） | 可上，不需要成人内容声明 | 有机会拿到 | 受众最广，可以在 B 站、抖音正常宣传 |
| 轻度擦边（性感服装、暧昧台词） | 可上，需填写成人内容调查 | 很难过审 | 国内只能走 Steam，短视频可能限流 |
| 成人内容 | 只能上成人分级，部分地区屏蔽 | 不可能 | 商店曝光大幅下降 |

另外两点：貂蝉、大小乔等是公版人物，但不要画成某款手游的皮肤样子；女性角色要有实打实的玩法作用、不能只当花瓶，不然容易在社区起负面节奏。以上是常识性建议，不替代律师意见。

## 非射击核心玩法

把射击换成“冷兵器近战 + 现代道具 + 夺将”。主角用捡来的刀枪剑戟打仗，穿越者身份带来一个现代道具栏，打败名将可以抽取他的装备。

### 操作（键鼠和手柄通用）

| 输入 | 动作 | 设计要点 |
| --- | --- | --- |
| WASD / 左摇杆 | 移动 | 负重越高越慢，接上搜打撤的“贪不贪” |
| 左键 | 普攻连招 | 武器决定连招：刀快、枪长、戟横扫、双股剑连击、弓为少数远程（非射击主导） |
| 右键 | 重击 / 蓄力 | 打破敌方架势，进入“破阵”状态 |
| 空格 | 翻滚 | 0.2 秒无敌，可充能 2 次，负重超标只剩 1 次 |
| Q | 现代道具 | 强光手电（致盲）、防狼喷雾（控场）、鞭炮（惊马）、望远镜（看宝物位置），有使用次数 |
| E | 夺将 | 对破阵的名将使用，抽取他的兵器、坐骑或将魂 |
| R | 武将附体 | 怒气满后召唤已收服的将魂附体 8 秒，如“单骑千里”冲锋、“当阳桥一吼”震慕 |
| F | 搜刮 / 交互 | 开箱要读条，越值钱越久，可被打断 |

### 三个独特卖点

1. **夺将**：名将是每场战役的“大红”。打败后可以抽取一件带名字的传说装备（方天画戟、丈八蛇矛、赤兔、的卢），但传说装备很重，带上就跑不快。
2. **历史修正力**：打斗、开箱、改变历史（如提前杀掉某将、救下本该死的人）都会涨修正值。到 50% 时空守卫入场，到 100% 战役最强的将领直接来抹掉你。它替代倒计时，也让“改写历史”变成风险换收益的选择。
3. **护送红颜**：部分战役里可以遇到历史女性，救下后她跟着你走，带到撤离点才算成功。她本身有战斗或辅助能力，但也会吸引追兵，是一个“活的大红”。

背包仍是俄罗斯方块式格子，胸口有一个 2×2 的“护心镜”安全格，死了也不掉。

### 敌人生态

| 类型 | 例子 | 作用 |
| --- | --- | --- |
| 杂兵 | 黄巾力士、曹军刀盾手、吴军弓手 | 常规敌人，掉粮草和铜钱 |
| 精英 | 虎豹骑、白毛兵、藤甲兵 | 有护甲和阵型，需要重击破阵 |
| 其他穿越者 | 同样来捡货的敌对穿越者小队 | 对应搜打撤里的敌对搜刮者，身上有现代道具和好货 |
| 时空守卫 | 无脸的铜甲人 | 历史修正力触发，硬、追得紧 |
| 名将 Boss | 吕布、关羽、张飞、典韦、许褚、太史慈 | 每场战役 1 到 2 位，可夺将 |

## 哈迪斯式肉鸽搜打撤循环

每局先选一场战役，战役内部是哈迪斯式的房间制地图，每个阶段末尾都能撤离。一局 15 到 25 分钟。

### 一局的流程

1. **出发**：在庄园选战役、兵器、现代道具、丹药和干粮。带进去的东西死了会丢。
2. **进房间**：战役分 3 个阶段，每阶段 6 到 9 个房间，门上显示奖励类型（将魂、材料、宝箱、商人、红颜、危险房）。
3. **打 + 搜**：清完房间开启搜刮点。不清也能潜行摸箱子，但修正值涨得更快。
4. **拿将魂**：每次三选一，只在本局有效。
5. **阶段末选择**：每阶段尽头有时空锚点，可以充能撤离；也可以继续深入，最后阶段是名将 Boss 和宝库。
6. **结算**：撤离成功带回全部物品和红颜；死亡只保留护心镜里的东西和 30% 时空碎片。
7. **回庄园**：卖货、升级建筑、和红颜互动、配装下一局。

| 局内（每局重置） | 局外（永久保留） |
| --- | --- |

## 基地养成：穿越者的坞堡庄园

基地沿用鸭科夫的思路：用局内带回的材料升级建筑，每栋建筑解锁一类功能。我们加一层“红颜”：每位红颜入住后管一栋建筑，并给出发配装加成。开局是一座破土房和时空裂隙，满级是一座热闹的坞堡。

| 建筑 | 对应鸭科夫功能 | 功能 | 升级材料示例 | 可入驻红颜 |
| --- | --- | --- | --- | --- |
| 库房 | 仓库 | 存放物品，每级加格子 | 木料、石料 | 糜夫人（管家，仓库扩容） |
| 屯田 | 食物 | 种粮做干粮，出发前吃拿增益 | 种子、农具 | 甄宓（产量增加） |
| 医庐 | 医疗 | 制作金疮药、麻沸散 | 草药 | 小乔（药效提升） |
| 铁匠铺 | 工作台 / 武器改装 | 打造、强化、修复传说兵器 | 生铁、精钢 | 祝融（火属性附魔） |
| 机关坊 | 特殊装备 | 用现代知识 + 古代工艺做道具（连弩、木牛流马、烟雾弹） | 齿轮、零件 | 黄月英（解锁高级图纸） |
| 马厩 | 新增 | 养马，马匹提高局内负重和翻滚次数 | 草料、马具 | 孙尚香（骑射训练） |
| 乐坊 | 新增 | 每局出发前选一首曲子当全局 buff | 乐器、书卷 | 蔡文姬、大乔 |
| 情报堂 | 任务 NPC | 发悬赏任务，提前透露名将位置 | 密信 | 貂蝉（间谍情报） |
| 集市 | 交易 | 卖货、买基础材料，每日刷新收购单 | 铜钱 | 无 |
| 时空裂隙 | 天赋 / 属性 | 升级时空腕表：生命、护心镜大小、撤离充能速度 | 时空碎片 | 无 |
| 名将阁 | 新增 | 陈列夺得的传说装备，集齐一套解锁套装属性 | 传说装备 | 无 |

### 红颜系统

- **获得**：每位红颜绑定一场战役，第一次需要完成护送撤离。护送失败可以重来，不会永久失去。
- **好感度**：用局内带回的礼物提升，如貂蝉喜欢铜镜、黄月英喜欢齿轮。这是大量普通战利品的去处，让每次摸到的小物件都有用。
- **好感奖励**：每级解锁一段剧情、一个庄园加成；满级后可带她进战役当伙伴，她倒下后本局不能再上，但不会永久死亡。
- **尺度**：剧情和立绘按全年龄做，可以有告白、同住、约会，不做成人内容。宣传时只用“红颜”一词，不用“后宫”。
- **终局**：集齐时空碎片后，穿越者可以选择回到现代，或者留在三国和红颜一起，形成多结局。这也点题“逃离三国”。

## 2D 还是 3D

结论：做 2D。一个人做 3D 不是做不了，但建模、绑骨、动画、材质、灯光每一项都是独立技能，美术工时大约是 2D 的 2 到 3 倍，而且 AI 出图目前对 2D 帮助远大于 3D。《哈迪斯》本身也是用 3D 渲染成 2D 精灵的，玩家看到的是 2D。

| 维度 | 2D（推荐） | 3D 低多边形 |
| --- | --- | --- |
| 美术产能 | AI 出图 + 手修即可用 | 需要建模和绑骨，AI 生成模型质量不稳定 |
| 角色动画 | 切片骨骼动画，一套底图做全部动作 | 可以用现成动作库，但风格统一难 |
| 打击感 | 靠帧冻结、震屏、粒子，完全够用 | 一样需要，并不更省事 |
| 俯视角层级与遮挡 | 需要处理 Y 轴排序和墙体半透明 | 自带深度，这是 3D 的主要优势 |
| 性能和平台 | 低配电脑和 Steam Deck 都轻松 | 需要优化 |
| 个人 1 年可产出 | 约 4 层地牢、30 种敌人、4 个 Boss | 约一半 |

### 推荐技术路线

- **引擎**：Godot 4。免费、轻量、2D 工具完整（TileMap、Y-Sort、Skeleton2D），GDScript 好让 Codex 帮写代码。如果你已经会 Unity，用 Unity 也可以。
- **画风**：高清手绘卡通，而不是像素。AI 出像素图的对齐和帧间一致性很差，手绘卡通可以拆分部件做骨骼动画。
- **动画**：角色拆成头、身体、左右手、左右脚、武器 7 个部件，在 Godot 里用 Skeleton2D 或 AnimationPlayer 做待机、跑、攻击、受击、死亡。只做左右两个朝向，翻转复用。
- **视角**：斜 45 度的三分之四俯视，墙体有高度，角色走到墙后时墙变半透明。
- **地牢**：房间用手工模板（每层 15 到 20 个），运行时随机拼接和随机刷怪、刷箱。不要做纯程序生成，个人调不好。
- **网络**：先做单机。鸭科夫也是单机，联机会把工作量翻倍。

## 美术设定

风格定位是“水墨底色的粗线条动作漫画”：角色比例略 Q（头身比 1:3），线条锐利、剥影清楚；场景是宣纸质感和水墨远景；战斗特效用高饱和度色块和墨迹飞溅。它和光荣系的写实武将、手游里的华丽皮肤都拉开距离。

### 风格关键词

- 粗墨线描边（3 到 4 像素，深褐 #2B1D16，不用纯黑）
- 平涂 + 一档硬阴影，少量宣纸纹理
- 武将用夸张剥影区分（吕布的雉翎、关羽的长髯），但服装设计按汉末制式自己画
- 场景低饱和、角色和可交互物高饱和，保证战斗可读性
- 现代道具用浅蓝色发光处理，和古代物品一眼可分

### 主角与角色

- **主角**：穿越前是外卖骑手，穿着破了的冲锋衣外套叠在汉代皮甲上，左手戴发光的时空腕表，背一个方形外卖箱当背包。外卖箱就是主角最好认的视觉符号，也是可以换的皮肤。可以提供男女两个主角。
- **名将**：体型是主角的 1.5 到 2 倍，各有一个标志性剥影和兵器。
- **红颜**：立绘按半身、细节更高的插画做，局内是和主角同比例的精灵。服装端庄，突出个性（孙尚香持弓、黄月英带工具、祝融带飞刀）。
- **时空守卫**：无脸铜甲人，身上有青蓝裂纹，和三国人物形成对比。

### 技术规格

- 基准分辨率 1920×1080，主角在画面中约 140 像素高，原图按 2 倍（280 像素）绘制。
- 地砖 128×128 像素，墙体高度 1.5 格。
- 图标 128×128，透明背景，统一 45 度左上光源。
- 红颜立绘 1600×2400，用于对话和庄园。
- 所有角色和物件 PNG 透明背景，角色单独出分部件版本。
- UI 用竹简 + 印章红，字体选可商用的开源字体（如思源宋体）。

## 开发里程碑

按一个人全职估算，从玩法原型到 Steam EA 约 12 到 15 个月。以下每一步过了再进下一步。

1. **第 1 到 2 个月，手感原型**：灰盒子角色 + 1 种武器 + 3 种敌人 + 夺将。通过标准：反复打 10 分钟不腻。
2. **第 3 到 4 个月，循环原型**：1 层地牢 + 背包 + 撤离 + 简单基地 3 栋建筑。通过标准：朋友试玩会主动说“再来一局”。
3. **第 5 到 6 个月，定美术、发商店页**：替换正式美术，做 30 秒宣传片，开 Steam 商店页收愿望单。
4. **第 7 到 10 个月，内容堆量**：4 层、全部派系赐法、4 个 Boss、完整基地。
5. **第 11 个月，Steam 新品节 Demo**：用前 2 层做试玩版，看愿望单和反馈。
6. **第 12 到 15 个月，EA 上线**。
