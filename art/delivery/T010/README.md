# T010 宝驹美术

主美交付：小毛驴加褡裢，待机、行走关键姿势、驮物三态。

| 状态 | 资源 | 内容 |
| --- | --- | --- |
| 待机 | `art/char/char_baoju_idle_01.png` | 灰褐小毛驴，空麻布双褡裢，四蹄站立 |
| 行走 | `art/char/char_baoju_walk_01.png` | 同造型迈步姿势，供动画参考 |
| 驮物 | `art/char/char_baoju_loaded_01.png` | 鼓起的双褡裢，背上扎紧粮袋与布卷 |

三张统一 384×320 RGBA PNG，显示倍率 0.5，显示画布 192×160，脚底地面锁点 `[192, 300]`，归一化 `[0.5, 0.9375]`。朝右，可水平镜像朝左；左上光源。原始生成图保留在 `sources/`，提示词见 `prompts.json`，每条均以前置 STYLE 开头；使用内置 imagegen。

## 对照范围

- 已完成任务板列出的三种状态、小毛驴和褡裢造型。
- 采用深褐粗线、平涂一档硬阴影与宣纸纹理，透明底，无文字、水印、Logo。
- 本批是三张关键姿势，不是连续行走帧或骨骼拆件；沿用 docs/03 的“美术交关键姿势参考”约定。动画由主程接入。
- T010 的详细尺寸和验收条目尚未补到 docs/03；画布、锁点和满载物件是本批提议，交主策确认。按用户本次指示先做 T010。
- 未改任务板、需求、代码或原型同步目录。

## 接入与检查

`assets.json` 提供尺寸、倍率、锁点、包围盒和 SHA-256；包围盒使用 alpha ≥ 32 标识可见轮廓，原始透明通道保留。`python art/delivery/T010/package.py` 可从原始生成图重建成品与检查记录。

`validation.json` 记录 RGBA、尺寸、透明通道、可见轮廓未裁切、文件大小检查。已人工检查浅底、深底及半尺寸显示。打开 `preview.html` 对照三态；预览截图不入库，PR 直接引用成品图片。

主程合并后需扩展 `tools/sync_art.py` 读取本批清单（当前只读取 T002），再同步美术；本 PR 仅交美术资产。行走图用于制作动画参考，不能直接视为循环动画。
