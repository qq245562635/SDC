## 尺寸口径：待主策确认

候选版保留原 PNG 尺寸和原竖向落脚包络，将原来的迈步横向延伸收回。两腿可见宽度按同款直腿成对拟合，没有保留斜腿弓步展开后的横向宽度。

这与“保留斜腿的径向长度”不同。例如联军兵近侧原图髋到脚径向约 90.52 源像素，但 PNG 高度只有 79；完全竖直保留该径向长，需要加高画布，并改变原静止脚底高度。当前候选在原画布内，测得约 56.95，远侧约 53.04，保留原竖向落脚高度。

该口径已在 PR 提请主策确认，不把这项差异视为已验收。若要求保留旧径向长，将据主策约定调整画布及落脚高度。
